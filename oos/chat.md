# Чат

Контейнер общения: дерево сообщений, участники и доступы. Чат — это лента
сообщений и место, где они осмысленно группируются. Чаты образуют дерево:
внутри чата могут создаваться новые чаты.

## Поля

- **id** — int, pk.
- **root_id** — fk, id = root_id для корня (корневой чат).
- **parent_id** — fk, can be null (для корня).
- **level** — глубина в дереве, 0 — корень; нужен для ограничения вложенности.
- **title** — 128 chars, can be null.
- **created_by_id** — участник, создавший чат.
- **created_at** — когда создан чат.
- **updated_at** — когда было последнее сообщение в чате (сообщения
  в дочерних чатах не считаются).
- **state** — OPEN / CLOSED, по умолчанию OPEN.
- **result_id** — can be null; сообщение только из этого чата, которое
  считается итогом этого чата. Может устанавливаться только владельцем чата.

## Состояния

- **Открыт** — в чат можно писать, приглашать участников, шарить сообщения.
- **Закрыт** — писать, приглашать, шарить больше нельзя; история читается.

## Поведение

- **Корневой чат — сессия.** Корневой чат привязан к воркстейшну и
  является рабочей сессией: один корневой чат на воркстейшн одновременно.
- **Вложенные чаты** создаются командой `#start <title>`: создатель попадает
  в новый чат один, остальные приглашаются явно через `#invite`.
- **Доступ** — через участников (ChatParticipant): доступ не наследуется
  на родительский или дочерние чаты, каждый чат требует отдельных доступов.
- **Шаринг** — участник может зашарить любое видимое ему сообщение в любой
  чат, где он участник. Шаринг создаёт в целевом чате копию сообщения со
  ссылкой на оригинал (см. «Сообщение»).
- **Закрытие** — закрытие корневого чата каскадно закрывает всё дерево
  дочерних чатов и прекращает всю активность на них.
- **Редактирование дерева чатов** не предусмотрено: `#start` создаёт новый
  узел, переструктуризация невозможна.

## Команды

Команды — это обычные сообщения, видимые всем, на которые есть
дополнительная реакция.

- `@UserName` — упоминание участника; для агентов — обязательный триггер ответа.
- `#invite @UserName` — создаёт доступ к текущему чату для участника.
  Любой участник чата может вызывать.
- `#kick @UserName` — удаляет доступ к текущему чату. Только владелец чата.
- `#start <Title>` — создаёт новый дочерний чат из текущего; создатель
  попадает в него один, остальные — по явным приглашениям. Любой участник
  чата может вызывать.
- `#end` — закрывает текущий чат. Только владелец чата. Если чат корневой —
  закрывает всё дерево.
- `#share <chat_id>` — шарит указанное сообщение в целевой чат. Механика —
  в объекте «Сообщение». Кнопка шаринга в веб-клиенте выполняет ту же
  команду под капотом (единый код-путь).

## Связи

- **Корневой чат является** СЕССИЕЙ воркстейшна.
- **Содержит** Участников (ChatParticipant) и Сообщения.
- **Создаётся из** родительского Чата (кроме корня).

## Вне рамок

- Привязка к проекту — через воркстейшн (корневой чат).
- Формирование ответа агентом — отдельный объект.
- Треды — производная группировка сообщений внутри чата, отдельной
  сущностью не хранятся (см. «Сообщение»).
