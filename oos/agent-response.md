# Агент-ответ

Формирование ответа агентом на новое сообщение в чате, где агент участвует.
Агент ведёт себя реактивно: реагирует на события в чате, а не только
вызывается по требованию.

## Поведение

- Агент — это Участник (`kind = agent`) с ролью из `roles/`.
- Агент участвует в чатах через ChatParticipant (по умолчанию — добавляется
  при активации роли на проекте/воркстейшне).
- Агент реагирует на новые сообщения в чатах, где участвует.
- Обязательный триггер — `@упоминание` агента. Прочие новые сообщения агент
  обрабатывает по релевантности (по правилам своей роли/промпта).
- Команды участников и команды агента идут в одну очередь и выполняются по
  одной (сериализация на воркстейшн).

## Контекст ответа

- При формировании ответа агент видит ТЕКУЩИЙ чат и один ближайший
  родительский чат, но только если у агента есть к нему доступ
  (ChatParticipant).
- Ответ агента — это обычное Сообщение в чате; его действия порождают
  Артефакты, прикреплённые к этому сообщению.

## Связи

- **Исполняет** роль агента (роль → Участник).
- **Пишет** Сообщения в Чатах.
- **Порождает** Артефакты.

## Вне рамок

- Механика подписки/очереди событий — инфраструктура.
- Внутренности агентского цикла (LLM → parse → exec → trace) — ядро фреймворка.
