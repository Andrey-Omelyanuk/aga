# Просмотр содержимого проекта в воркстейшне

Хочу видеть, что сейчас лежит в проекте, над которым работает агент: дерево
папок и файлов, и открывать файл, чтобы посмотреть его — текст, картинки,
видео и аудио. Полных фич IDE не нужно, на первое время достаточно подсветки
синтаксиса. Менять файлы я напрямую не могу и не хочу: правки делает только
LLM по моей просьбе. Проект физически живёт внутри воркстейшна (`/work/project`),
поэтому просмотр привязан к воркстейшну. Как и видимость сессий, смотреть
содержимое может любой участник.

## Поведение
- открытый воркстейшн показывает дерево папок и файлов проекта
- открытие текстового файла показывает его содержимое с подсветкой синтаксиса по расширению
- открытие изображения показывает картинку в браузере
- открытие видео и аудиофайлов проигрывает их в браузере
- просмотрщик не позволяет изменять файлы: правки делаются только через чат с LLM
- каждый участник видит содержимое любого воркстейшна
