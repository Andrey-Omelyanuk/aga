# Подсветка синтаксиса на странице файлов

На странице «Файлы» выбираю файл в дереве и хочу видеть содержимое с
подсветкой синтаксиса: код — по языку расширения, markdown — как исходник с
подсветкой. Сейчас текст показывается плоским моноширинным, без цветов.
Подсветку делаем готовой библиотекой highlight.js — она уже в проекте
(подсвечивает код в каталоге скиллов и команд). Просмотр остаётся только
чтением: правки проекта — по-прежнему только через чат с LLM.

## Поведение
- выбранный текстовый файл показывается с подсветкой синтаксиса по языку его расширения
- markdown-файл показывается как исходник с подсветкой markdown-разметки, а не готовым документом
- файл с неизвестным расширением показывается без подсветки, обычным текстом
