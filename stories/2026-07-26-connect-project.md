# Подключение фреймворка aga к проекту

**Источник:** `/story` — голос пользователя

## Что хочет разработчик

Подключить фреймворк aga к своему проекту для работы LLM-агентов над этим
проектом. Проект может быть как **новым** (только создан, пустая директория),
так и **существующим** с большой кодовой базой.

Подключение — это действие, после которого:
1. В проекте появляется `AGENTS.md` (если его ещё нет).
2. Агенты настроены и готовы работать над проектом.

## Сценарии

### Сценарий A: новый проект
1. Разработчик создаёт пустую директорию проекта.
2. Выполняет `aga init /path/to/project` (или эквивалентное API-действие).
3. aga создаёт в проекте `AGENTS.md` с минимальной конфигурацией.
4. aga подбирает роли агентов по умолчанию и активирует их на проекте.
5. Разработчик донастраивает агентов под свои задачи.

### Сценарий B: существующий проект
1. Разработчик указывает путь к существующему проекту.
2. aga сканирует кодовую базу: определяет стек, инфраструктуру (есть ли
   `docker-compose.yml`, `Dockerfile`, `Cargo.toml`, `package.json` и т.д.).
3. Если `AGENTS.md` уже есть — не трогает (но может предупредить).
4. Если `AGENTS.md` нет — создаёт на основе сканирования.
5. На основе сканирования подбирает и активирует агентов, релевантных проекту.
   - Например, для проекта с Docker → docker-helper, app-deployer.
   - Для Rust-проекта → rust-ассистент.
   - Для JS/TS → frontend-ассистент.
6. Разработчик может добавить/убрать агентов постфактум.

### Сценарий C: повторное подключение
1. Проект уже подключён (есть AGENTS.md, агенты активны).
2. Разработчик повторно запускает `aga init`.
3. aga проверяет актуальность конфигурации: не появились ли новые сервисы, не
   изменился ли стек.
4. Если нужно — обновляет AGENTS.md и список агентов (с подтверждением).

## Что НЕ входит в историю

- Создание самих агентов (ролей) — они уже есть в `roles/` библиотеке пресетов.
- Аутентификация и мультитенантность — пока всё локально.
- Управление проектом после подключения (запуск задач, трейсинг) — этим
  занимаются другие части фреймворка.
