# Чат обновляется по WebSocket (Centrifuge)

Сейчас страница чата обновляется опросом каждые 2 секунды: реактивные ответы
агентов приходят асинхронно, и пока нет websocket, клиент перезагружает чат по
таймеру. Это лишние запросы и задержка. Переводим обновление чата на реальное
время через Centrifuge (websocket). Для начала — один общий канал для всех,
но доступен он только аутентифицированным пользователям (по JWT, который выдаёт
ядро). Отдельных каналов на чат пока не делаем; авторизацию по каналам не
вводим — канал общий, гейт — сам факт входа. Polling в чате убираем полностью:
если websocket недоступен, чат открывается, но автообновления нет.

## Поведение
- отправленное сообщение появляется у всех открывших чат без перезагрузки страницы
- ответ реактивного агента появляется в чате без опроса по таймеру
- канал обновлений доступен только аутентифицированным пользователям: неаутентифицированный не получает connection-JWT и не может подключиться
- страница чата больше не опрашивает сервер по таймеру
