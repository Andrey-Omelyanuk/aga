# AgentSet: набор агентов на проект

Хочу AgentSet — именованный набор агентов, который настраивается один раз и
цепляется на разные проекты. Сейчас агентов описывают глобальные роли
(roles.yaml, project_roles) с пер-ролевыми промптами и командами; настройка
не переиспользуется между проектами. Вместо этого — набор агентов: каждый
агент отвечает за свой уровень, у него свои правила на этом уровне и свои
настройки LLM. Отдельно skills/rules/commands не выделяем — всё в описании
агента. Набор живёт в БД и настраивается через API. Прикреплённый к проекту
набор заменяет прежнюю настройку ролей. Агенты набора выстроены в дерево,
повторяющее иерархию папок проекта: у папки свой агент, подпапки — его
наследники. Старые глобальные роли и пресеты из main/roles/ исчезают —
агентов проекта определяет только прикреплённый набор.

## Поведение
- созданный через API набор агентов виден в списке наборов
- участник прикрепляет набор к проекту — у проекта появляются агенты набора
- один набор можно прикрепить к нескольким проектам, и во всех действуют его агенты
- прикреплённый набор заменяет прежние роли проекта: работает только набор
- замена набора у проекта меняет его агентов на агентов нового набора
- у каждого агента набора свои правила, разрешённые команды и настройки LLM
- агенты набора образуют дерево по иерархии папок проекта: у папки агент, у подпапок — его наследники
- в чате @Agent.<имя> вызывает агента из набора проекта с его правилами и LLM
- ручная настройка ролей и глобальные роли (roles.yaml, /roles, /projects/:id/roles) исчезают
