# Территория, скиллы, команды и инструменты набора агентов

Набор агентов — команда для проекта, и каждый агент в ней работает на своей
территории: он владеет папками и файлами своего узла в дереве набора (дерево
остаётся и теперь задаёт территорию). Способности агента — скиллы и команды —
это общий каталог с версиями: агент получает скилл или команду по имени и может
зафиксировать версию; без фиксации всегда берётся последняя. Отдельно от них —
инструменты: список исполняемого в консоли воркстейшна, версий у инструментов
нет. У набора появляется отдельная страница, где виден и правится весь состав.
Чужую территорию агент может читать, но менять — никогда: граница только на
изменения. Команды чата (#start, #invite, #kick, #end, #share) — это сообщения
в чате, а не способности агента: в каталог версий они не входят.

## Поведение
- у каждого агента набора своя территория — папки и файлы его узла в дереве набора
- выполнение инструмента, меняющего файл вне территории агента, не проходит: файл остаётся прежним
- выполнение инструмента, который только читает файл вне территории агента, проходит — чтение не ограничено
- агент выполняет в консоли воркстейшна только инструменты своего списка
- у инструментов нет версий: версии есть только у скиллов и команд
- агент использует только данные ему скиллы и команды; остальные из каталога ему недоступны
- у агента без зафиксированной версии скилл или команда используются в последней версии, и новая версия каталога подхватывается без настройки
- агент с зафиксированной версией скилла или команды продолжает использовать её после выхода новой версии
- на отдельной странице набора виден состав: агенты, территория каждого, данные скиллы и команды с версиями, инструменты
- изменения состава на странице набора сохраняются и остаются видимыми после обновления
- вызов @Agent.<имя> в чате применяет территорию и скиллы с командами и инструментами агента из набора проекта
