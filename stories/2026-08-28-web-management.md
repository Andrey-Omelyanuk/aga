# Веб-управление проектами, сессиями и воркстейшнами

Управляю своими проектами и сессиями в них через веб-интерфейс. Рабочие
станции не управляются из интерфейса: видно, какие есть и в каком они
состоянии, и их можно занимать своими сессиями. Проекты и сессии видят все
участники. Люди попадают в aga из SSO (Keycloak): участник создаёт проекты и
открывает сессии, роли приходят из realm-ролей Keycloak. Пока все участники
видят все проекты и сессии — персональной видимости нет. Админ — внешняя
сущность (доступ к SSO и Kubernetes, поднимает станции), в aga его нет.
Закрыть сессию может только тот, кто её открыл.

## Поведение
- участник, вошедший через SSO, видит все проекты
- участник, вошедший через SSO, видит все сессии всех проектов
- участник создаёт проект по git-URL, и проект сразу виден всем участникам
- участник открывает сессию на готовом воркстейшне, сессия привязана к этому воркстейшну
- пока на воркстейшне есть открытая сессия, новую на нём открыть нельзя
- закрыть сессию может только участник, открывший её (владелец)
- участник не может закрыть сессию, которую открыл другой участник
- закрытая сессия освобождает воркстейшн — на нём снова можно открыть сессию
- в интерфейсе видно воркстейшны и их состояние, но создавать и удалять их интерфейс не позволяет
- вкладка «Персонал» показывает участников из SSO и не даёт изменять их внутри aga
- вход в веб-клиент идёт через Keycloak, запросы с недействительным токеном отклоняются
- без SSO локальный запуск работает под аноним-суперпользователем, как сейчас
