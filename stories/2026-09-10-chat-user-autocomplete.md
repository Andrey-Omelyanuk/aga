# Автодополнение участников по «@» в поле чата

В чате при наборе сообщения хочется так же, как у сокращений по `/`, видеть
подсказку по участникам: набираешь `@` — под полем выпадает список людей —
участников открытого чата, по мере набора он фильтруется, а Tab дополняет
выбранное имя и сама ставит пробел — не надо помнить логины наизусть. Это
чисто помощь при вводе: как работают упоминания после отправки, не меняется —
`@имя` остаётся в видимом тексте сообщения. В списке только люди (участники с
видом human): агенты-участники в него не попадают — их вызов отдельная история.
Подсказка работает в основном поле ввода сообщения; в поле ввода нити и в
заголовок нити она не входит. Сокращения по `/` в эту историю не входят.

## Поведение
- при вводе `@` в начале текущего слова (в начале сообщения или после пробела) под полем появляется список людей — участников открытого чата
- по мере набора после `@` список фильтруется: остаются люди, чьи имена начинаются с набранного текста
- пункт списка показывает имя участника
- агенты-участники в списке не показываются
- если в открытом чате нет людей-участников или ни одно имя не начинается с набранного текста, список не показывается
- стрелки вверх и вниз перемещают выбор по списку
- Tab дополняет выбранное имя до `@имя` и вставляет после него пробел, список закрывается
- клик по пункту списка дополняет имя, как Tab
- Enter при открытом списке дополняет, как Tab; без открытого списка Enter отправляет сообщение, как раньше
- Escape закрывает список, оставляя набранный текст как есть
- дополненное `@имя` остаётся в видимом тексте сообщения и уходит при отправке
