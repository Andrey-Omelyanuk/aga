# Изменения проекта на странице сессии

На странице сессии (чата воркстейшна) нужна ссылка на отдельную страницу
Changes: по ней видно, что изменилось в проекте за время работы агента.
Изменения берём из git внутри воркстейшна — это дифф текущего состояния
ветки ws-<id> против дефолтной ветки репозитория (точки, где ветка началась
при клоне). Показываем всё текущее состояние: закоммиченное, незакоммиченное
и новые файлы, которые агент создал, но не коммитил. Если базы нет (пустой
git-репо, агент наполняет проект с нуля), весь проект показывается как новые
файлы.

Страница только показывает изменения: коммитить и пушить она не даёт, правки
проекта — по-прежнему только через чат с LLM.

## Поведение
- на странице сессии есть ссылка на страницу Changes её воркстейшна
- страница Changes показывает изменения файлов проекта против дефолтной ветки репозитория: закоммиченные на ветке и незакоммиченные правки
- созданный агентом, но не закоммиченный файл показан в Changes как добавленный
- в воркстейшне с пустым git-репо (нет дефолтной ветки) все файлы проекта показаны в Changes как добавленные
- при отсутствии изменений страница Changes показывает, что изменений нет
- у чата без воркстейшна (не сессии) ссылки на Changes нет
- страница Changes только показывает изменения: возможности закоммитить или запушить на ней нет
- каждый участник видит Changes любого воркстейшна, как и содержимое проекта
