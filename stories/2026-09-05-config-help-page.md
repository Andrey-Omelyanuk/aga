# Справка о конфиге и составе набора агентов

Нужна страница Help в разделе Config: понятно, из чего состоит набор агентов
(в виде диаграммы) и из чего вообще состоит конфиг платформы. Это справка для
того, кто впервые настраивает aga, — статический текст, который не зависит от
того, что реально настроено. Содержимое справки о самом конфиге ограничиваем
разделом Config (Env, Users, Skills, Commands, Agent Set, LLM), рантайм
(проекты, воркстейшны, сессии, файлы, чат) не описываем. Диаграмму состава
агент-сета рисуем SVG/HTML-компонентом без новых зависимостей. Языков два —
русский и английский, переключаются на самой странице; при первом открытии
справка на русском.

## Поведение
- на вкладке Config появляется пункт «Help», открывающий страницу справки
- на странице Help состав набора агентов показан диаграммой: агенты деревом по папкам проекта, у каждого территория, данные скиллы и команды по имени, инструменты и выбранное подключение к LLM
- на странице Help описан состав всего конфига: Env, Users, Skills, Commands, Agent Set, LLM
- при первом открытии справка показывается на русском языке
- переключатель En/Ru меняет язык справки, и выбранный язык сохраняется после перехода по страницам
- текст справки одинаков при любой настройке платформы: это документация, а не список сохранённых данных
